# Typing Remini

**레미니 캐릭터가 키보드 입력에 반응하는 Windows 타이핑 펫**

조타 · 리뿌 · 밍 · 얌 · 째로밍

[다운로드](../../releases/latest) · [문제 제보](../../issues) · [개발자 GitHub](https://github.com/Adam-yam)

</div>

---

Typing Remini는 바탕화면에 캐릭터를 표시하고, 키보드 입력과 마우스 클릭에 맞춰 손을 움직이는 프로그램입니다. 각 캐릭터의 2D·3D 모습 중 하나를 선택할 수 있으며, 입력이 없으면 졸리거나 잠든 모습으로 바뀝니다.

## 주요 기능

- **10종의 캐릭터** — 레미니 5종의 2D·3D 스타일 선택
- **타이핑 반응** — 좌우 손을 번갈아 움직이거나 입력 키에 따라 손 구분
- **마우스 반응** — 마우스 클릭에 맞춘 손동작
- **통통 튀는 효과** — 캐릭터와 키보드가 함께 움직이며 강도를 1~5단계로 조절
- **졸림·수면** — 일정 시간 입력이 없으면 상태 전환, 입력이 들어오면 복귀
- **바탕화면 표시 설정** — 크기 조절, 항상 위에 표시, 위치 잠금과 클릭 통과
- **자동 저장** — 설정을 변경하면 자동으로 적용·저장

## 다운로드 및 실행

**Windows PC와 .NET Framework 4.8이 필요합니다.**

1. [Releases](../../releases/latest)에서 Windows용 실행 ZIP을 다운로드합니다.
2. ZIP을 **모두 압축 해제**합니다.
3. `TypingRemini.exe`를 실행합니다.

`TypingRemini.exe.config`는 실행 파일과 같은 폴더에 두세요. 전체 소스 패키지를 받은 경우 실행 파일은 `dist` 폴더에 있습니다. GitHub의 `Source code (zip)`은 일반 사용자용 실행 패키지와 다릅니다.

업데이트할 때는 기존 프로그램을 트레이 메뉴에서 완전히 종료한 뒤 새 실행 파일을 실행하세요.

## 사용 방법

| 조작 | 기능 |
|---|---|
| 캐릭터 드래그 | 바탕화면에서 위치 이동 |
| 캐릭터 우클릭 | 설정, 표시 상태 등 메뉴 열기 |
| 트레이 아이콘 더블클릭 | 설정 창 열기 |
| 트레이 메뉴의 입력 반응 일시정지 | 입력 반응 일시 중지·재개 |
| 펫 숨기기 / 다시 표시 | 캐릭터 표시 전환 |

설정 창을 닫아도 프로그램은 트레이에서 계속 실행됩니다. 완전히 종료하려면 트레이 메뉴에서 종료를 선택하세요.

위치 잠금을 켜면 캐릭터 위의 클릭이 아래 창으로 전달됩니다. 이 상태에서는 트레이 메뉴를 이용하세요.

## 설정

### 캐릭터

**조타 → 리뿌 → 밍 → 얌 → 째로밍** 순서로 표시됩니다. 2D·3D 스타일을 선택한 뒤 원하는 캐릭터를 누르면 바로 적용됩니다.

### 크기와 움직임

| 설정 | 설명 |
|---|---|
| 캐릭터 크기 | 100~700, 기본값 220. 실제 표시 크기는 Windows 배율에 따라 조정 |
| 손 동작 유지 | 60~500ms, 기본값 120ms |
| 왼손과 오른손 구분 | 켜면 키의 구분에 맞춰 반응, 끄면 양손이 번갈아 반응 |
| 통통 튀는 효과 | 전체 이미지의 통통 튀는 움직임 켜기·끄기 |
| 통통 효과 강도 | **1~5단계, 기본값 1단계** |
| 부드러운 수면 전환 | 졸림·수면으로 바뀔 때 부드럽게 전환 |
| 마우스 클릭 반응 | 클릭에 맞춰 손동작 표시 |
| 마우스 사용 중 깨어 있기 | 이동·클릭·스크롤이 감지되면 수면 대기 시간 갱신 |

### 입력 대기

| 설정 | 기본값 / 범위 |
|---|---|
| 졸림과 수면 | 켜짐 |
| 졸리기 시작 | **30초**, 5~300초 |
| 잠들기 시작 | **90초**, 10~1,800초. 졸림보다 최소 5초 이후 |

마우스 사용 중 깨어 있기가 켜져 있으면 키보드를 사용하지 않아도 마우스 활동이 수면을 미룹니다.

### 표시와 실행

| 설정 | 설명 |
|---|---|
| 항상 위에 표시 | 캐릭터를 다른 창 위에 표시 |
| 위치 잠금 | 드래그 방지 및 클릭 통과 |
| 작업표시줄에 표시 | 캐릭터 창의 작업표시줄 표시 여부 |
| 로그인하면 자동 실행 | Windows 로그인 시 프로그램 실행 |
| 숨기기 단축키 | 사용 안 함 / Ctrl + Alt + H / Ctrl + Shift + H / Alt + Shift + H |
| 위치 초기화 | 캐릭터 위치를 기본 위치로 이동 |

일반 설정은 변경 후 자동으로 적용·저장됩니다. `설정 저장` 버튼으로 다시 저장할 수도 있습니다. 다른 프로그램과 충돌해 단축키를 등록하지 못하면 기존 단축키를 유지하고 오류를 표시합니다.

## 입력 처리와 개인정보

Typing Remini는 다른 창에서 타이핑할 때도 반응하기 위해 **시스템 전체의 키 누름·뗌 이벤트와 키 구분**을 처리합니다. 마우스 옵션을 사용하면 클릭 및 이동·스크롤 이벤트도 처리합니다.

현재 소스에는 입력한 문장을 조합해 저장하거나, 키 입력 기록을 외부 서버로 전송하는 기능이 없습니다. 사용자 설정과 오류 기록은 로컬에 저장됩니다. 앱 정보의 GitHub 버튼은 사용자가 누를 때 기본 브라우저로 웹페이지를 엽니다.

- 설정·오류 기록 위치: `%AppData%\ScenePet`
- 기존 버전과의 설정 호환성을 위해 저장 폴더 이름을 유지합니다.
- 자동 실행은 해당 옵션을 켠 경우에 등록합니다.
- 기본 실행에 관리자 권한을 요구하지 않습니다.

## VirusTotal 및 백신 탐지 안내

**일부 백신에서 오탐이 발생할 가능성이 있습니다. 다만 탐지 수가 적거나 머신러닝 기반 탐지명이라는 이유만으로 모든 경고를 오탐으로 확정하지는 않습니다.**

VirusTotal은 여러 보안 엔진의 결과를 보여주며, 정상 파일이 악성으로 분류되는 오탐도 다룹니다. 탐지명과 개수는 판단에 참고할 정보이며, 특정 파일의 안전성을 보증하는 인증은 아닙니다. [VirusTotal 공식 설명](https://docs.virustotal.com/docs/how-it-works)

Typing Remini는 타이핑 반응을 위해 Windows의 전역 키보드 입력 감지 기능을 사용합니다. 이 기능을 사용한다는 사실과 실제 악성 행위 여부는 구분해야 합니다. **현재 확인한 탐지가 이 기능 때문에 발생했다는 원인은 확정되지 않았습니다.**

### 공유된 검사 화면

개발 과정에서 공유된 `TypingRemini.exe` 검사 화면에는 **70개 엔진 중 5개 탐지**가 표시되었습니다.

| 엔진 | 화면에 표시된 탐지명 |
|---|---|
| CrowdStrike Falcon | `Win/malicious_confidence_70% (D)` |
| Elastic | `Malicious (moderate Confidence)` |
| MaxSecure | `Trojan.Malware.300983.susgen` |
| SecureAge | `Malicious` |
| Trapmine | `Suspicious.low.ml.score` |

이 결과는 해당 화면의 파일에 한정됩니다. 재검사나 엔진 업데이트에 따라 결과는 달라질 수 있습니다. 특히 CrowdStrike의 **`malicious`** 탐지는 아래 참고 사례의 **`grayware`** 탐지와 동일한 이름이 아닙니다.

화면에 표시된 SHA-256:

```text
035db4f164bde73d980c829e7438a810ea79d9483175fd23ff2e2d9222b30dfe
```

[해당 해시의 VirusTotal 보고서](https://www.virustotal.com/gui/file/035db4f164bde73d980c829e7438a810ea79d9483175fd23ff2e2d9222b30dfe/detection)

**배포용 `Typing_Remini_1.0.0_Windows.zip`에 포함된 `TypingRemini.exe`의 SHA-256이 위 검사 화면과 일치함을 확인했습니다.** EXE 크기는 5,489,664바이트입니다. 위의 5/70 탐지 내역은 이 파일의 공유된 검사 화면 기준이며, 현재 실시간 재검사 결과를 뜻하지 않습니다. 이후 실행 파일이 변경되면 해시와 검사 보고서도 함께 갱신해야 합니다.

### 참고 자료와 해석 범위

아래 자료는 탐지명과 유사 신고 사례를 이해하기 위한 참고 링크입니다. **Typing Remini의 파일에 대해 백신 업체가 발급한 오탐 확인서는 아닙니다.**

- [VirusTotal — How it works](https://docs.virustotal.com/docs/how-it-works): 정상 파일이 하나 이상의 엔진에서 악성으로 분류되는 오탐이 존재함을 설명하는 공식 자료입니다.
- [Wox 이슈 #2916](https://github.com/Wox-launcher/Wox/issues/2916): Wox 실행 파일에서 `Win/malicious_confidence_60% (W)`와 `Suspicious.low.ml.score`가 보고된 사례입니다. 유사 탐지명이 다른 프로젝트에서도 나타났다는 근거이며, 이슈가 닫혀 있다는 사실만으로 오탐 확정을 뜻하지는 않습니다.
- [Trapmine 탐지명 설명 글](https://trojan-killer.net/trapmine-suspicious-low-ml-score-guide/): `Suspicious.Low.ML.Score`라는 이름만으로 악성 또는 안전을 확정할 수 없으며, 파일 출처·해시·분석·업체 확인이 필요하다고 설명합니다.
- [Hackerdose 설명 글](https://hackerdose.com/malware/suspicious-low-ml-score-false-positive/): 오탐 가능성을 다루지만 악성 가능성과 제거 안내도 포함합니다. 모든 동일 탐지가 오탐이라는 근거로 사용할 수 없습니다.
- [2-spyware 설명 글](https://www.2-spyware.com/remove-malicious-moderate-ml-score.html): `Malicious.moderate.ml.score`의 오탐 가능성과 악성 가능성을 함께 설명합니다. 해당 글은 Trapmine의 탐지명을 다루며, 위 화면의 Elastic 탐지에 대한 직접 분석이 아닙니다.
- [Reddit의 CrowdStrike 사례](https://www.reddit.com/r/crowdstrike/comments/12ckd08/detection_due_to_wingrayware_categorization/): TeamViewer 관련 파일의 `Win/grayware` 분류에 대해 사용자가 문의한 글입니다. Typing Remini에 대한 분석이나 업체의 공식 판정은 아닙니다.
- [Technopat의 관련 질문](https://www.technopat.net/sosyal/konu/virustotalin-win-grayware_confidence_70-d-tespit-ettigi-dosya-virus-mudur.3669434/): `Win/grayware_confidence_70%`를 다루는 참고 링크입니다. 작성 시 본문을 확인하지 못해 결론의 근거에는 포함하지 않았습니다.

### 파일 확인과 제보

배포 파일은 이 저장소의 Releases에서 받으세요. 해시는 PowerShell에서 확인할 수 있습니다.

```powershell
Get-FileHash .\TypingRemini.exe -Algorithm SHA256
```

해시 일치는 같은 파일인지를 확인하는 방법이며, 그 자체로 무해함을 증명하지는 않습니다. 경고가 나타나면 프로그램 버전, SHA-256, 백신 이름, 탐지명과 보고서 링크를 함께 [Issues](../../issues)에 남겨주세요. 경고를 무시하도록 백신을 끄거나 무조건 예외 처리하는 방법은 안내하지 않습니다.

## 자주 묻는 질문

**캐릭터가 보이지 않아요.**  
트레이 메뉴에서 다시 표시를 선택하거나 일반 설정의 위치 초기화를 사용하세요.

**캐릭터를 이동할 수 없어요.**  
위치 잠금이 켜져 있는지 확인하세요. 잠금 해제는 트레이 메뉴에서도 가능합니다.

**키보드를 사용하지 않는데 잠들지 않아요.**  
마우스 사용 중 깨어 있기가 켜져 있으면 마우스 활동도 수면 시간을 갱신합니다.

**일부 게임이나 프로그램에서 반응하지 않아요.**  
전체 화면 게임, 관리자 권한 프로그램 또는 보안 제한이 있는 환경에서는 표시·입력 감지가 제한될 수 있습니다.

## 운영 방침과 권리 존중

Typing Remini는 팬이 제작한 비공식·비영리 프로젝트입니다. 이 프로그램으로 수익을 창출할 계획이 없으며, 프로그램 내 광고도 넣지 않을 예정입니다.

캐릭터 및 관련 이미지의 저작권과 기타 권리는 각 권리자에게 있습니다. 제작자는 권리자의 권리를 존중하며, 권리자로부터 삭제 또는 배포 중단 요청을 받으면 관련 자료를 삭제하고 배포를 중단하겠습니다. 프로그램이나 소스 코드의 공개가 캐릭터 이미지의 자유로운 재사용 또는 상업적 이용 허가를 의미하지는 않습니다.

권리 관련 문의는 [GitHub Issues](../../issues)를 통해 전달해 주세요.

## 소스 코드 공개

백신 탐지와 오탐 가능성에 의문을 가질 수 있다는 점을 이해합니다. 사용자가 프로그램의 동작을 직접 살펴볼 수 있도록 실행 파일과 함께 소스 코드도 공개할 예정입니다.

입력 감지 방식, 설정 저장, 외부 통신 여부 등이 궁금하다면 공개된 코드를 직접 검토하셔도 좋습니다. 소스 패키지에는 직접 빌드할 수 있는 프로젝트와 빌드 파일도 포함합니다. 의심스러운 동작이나 개선할 부분을 발견하면 [Issues](../../issues)에 알려주세요.

소스 공개는 검토 가능성을 높이기 위한 조치이며, 백신 탐지가 모두 오탐임을 증명하거나 배포 실행 파일과 소스의 일치를 자동으로 보증하는 것은 아닙니다.
